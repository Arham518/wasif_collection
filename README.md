# Rana Collection

Rana Collection is an e-commerce website built to provide customers with a convenient way to browse fashion products online. The project includes a product catalog, product image management, customer authentication, and an admin dashboard for managing store products.

## Overview

The website is built with React and uses Supabase for database operations and authentication. The interface is designed to provide a straightforward shopping experience across desktop and mobile devices.

## Key Features

* Browse available fashion products.
* View product information and images.
* Customer authentication.
* Admin dashboard for product management.
* Add and update product listings.
* Store product information in Supabase.
* Responsive design for different screen sizes.

## Technologies Used

* React.js
* Vite
* JavaScript
* CSS / Tailwind CSS
* Supabase
* Netlify

## Local Development

### Prerequisites

* Node.js
* npm
* Supabase project credentials

### Setup

Clone the repository and install the dependencies:

```bash
git clone https://github.com/Arham518/wasif_collection.git
cd wasif_collection
npm install
```

Create a `.env` file in the project root and configure the required Supabase environment variables:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_publishable_key
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
